# アンケートシステム 利用者マニュアル

## システムの概要

知的障害者向けのアンケートシステムです。大きな絵文字とひらがなで直感的に回答できます。
複数のアンケートを管理でき、設問・選択肢のカスタマイズや結果のCSV出力が可能です。

---

## 起動方法

`index.html` をブラウザで直接開いてください。

```
ファイルをダブルクリック → ブラウザで開く
```

または、ローカルサーバーで配信する場合：

```bash
python3 -m http.server 8080
```

→ ブラウザで `http://localhost:8080/` にアクセス

---

## 回答者の操作手順

### 1. スタート画面

システムを開くと「アンケートにこたえよう！」というスタート画面が表示されます。
**「はじめる」ボタン**を押すとアンケートが始まります。

### 2. 質問への回答

- 質問が1問ずつ表示されます
- 上部のドットで現在の進行状況がわかります（● が現在の問、● が回答済み）
- 絵文字とひらがなのボタンを1つ選んでタップしてください
- 回答すると自動的に次の質問へ進みます

### 3. 完了画面

すべての質問に答えると「ありがとう！」画面が表示されます。
**「もういちど」ボタン**を押すと最初のスタート画面に戻ります。

## 管理者画面

URLの末尾に `?admin` を付けるとアクセスできます。

```
例: http://localhost:8080/?admin
```

### アンケート一覧

管理者画面を開くと、作成済みのアンケートが一覧表示されます。

| ボタン | 説明 |
|---|---|
| ＋ 新しいアンケート | 新しいアンケートを作成します |
| つかう | そのアンケートを回答画面に表示します |
| 詳細 → | 結果の確認・設問の編集画面へ移動します |
| 名前を変更 | アンケート名を変更します |
| 削除 | アンケートを削除します（現在表示中のものは削除できません） |

> **表示中** と表示されているアンケートが、回答者に見えているアンケートです。

### 詳細画面

アンケートの「詳細 →」を押すと詳細画面に移動します。

#### 結果の確認

- 各設問ごとに回答件数の棒グラフと平均スコアが表示されます
- 最近の回答が絵文字で一覧表示されます

#### 結果のエクスポート

**「CSVでだす」ボタン**を押すと、回答データをCSVファイルとしてダウンロードできます。
Excel で開く場合も文字化けしません（BOM付きUTF-8形式）。

CSVの列構成：

```
日時, Q1スコア, Q1回答, Q2スコア, Q2回答, ...
```

#### 結果の共有

**「共有」ボタン**を押すと、集計結果を他のアプリ（メモ、メール等）に共有できます。

#### データの削除

**「データをけす」ボタン**を押すと、そのアンケートの全回答データを削除します。
**この操作は元に戻せません。** 確認ダイアログが表示されます。

## 設問・選択肢のカスタマイズ

詳細画面の下部に編集フォームがあります。

### 設問テキストの変更

各設問のテキストエリアに直接入力して変更できます。

### 選択肢ラベルの変更

各選択肢のテキストボックスに直接入力して変更できます。
絵文字は回答数に応じて自動で割り当てられます（😄 〜 😢）。

### 設問・選択肢の追加と削除

| ボタン | 説明 |
|---|---|
| ＋ 設問を追加 | 設問を1つ追加します |
| 設問を削除 | その設問を削除します（設問が1つの場合は削除できません） |
| ＋ 選択肢を追加 | その設問に選択肢を1つ追加します |
| 削除（選択肢横） | その選択肢を削除します（選択肢が1つの場合は削除できません） |

### 保存とキャンセル

| ボタン | 説明 |
|---|---|
| 保存する | 編集内容を保存します（画面下部またはスクロール後に表示） |
| キャンセル | 編集内容を破棄し、最後に保存した状態に戻します |

---

## データについて

- 回答データはブラウザの **localStorage** に保存されます
- **ブラウザのデータを消去すると、回答データも削除されます**
- 定期的に「CSVでだす」でバックアップを取ることをおすすめします
- データは端末間で自動同期されません（別のPCやスマートフォンでは別々に管理されます）
